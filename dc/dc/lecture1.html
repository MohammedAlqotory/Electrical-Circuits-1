Chapter (2): Simple Resistive Circuits

Series, Parallel, Voltage & Current Division, and Star-Delta Transformations

2.1 Resistors in Series

When resistors are connected in series, they are joined end to end so that the same current flows through each resistor. The total resistance of the circuit is equal to the sum of the individual resistances, which means the overall resistance increases as more resistors are added in series. This type of connection is commonly used when a higher resistance is needed or when it is necessary to divide voltage across different components[cite: 2].

The total equivalent resistance, the circuit current and the voltage across each resistor can be calculated using the following[cite: 2]:

\[ R_T = R_1 + R_2 + R_3 \] \[ v_T = v_1 + v_2 + v_3 \] \[ i_1 = i_2 = i_3 = i \] \[ i = \frac{v_T}{R_T} = \frac{v_T}{R_1 + R_2 + R_3} \] \[ v_1 = i R_1 = v_T \frac{R_1}{R_1 + R_2 + R_3} \] \[ v_2 = i R_2 = v_T \frac{R_2}{R_1 + R_2 + R_3} \] \[ v_3 = i R_3 = v_T \frac{R_3}{R_1 + R_2 + R_3} \]

2.2 Resistors in Parallel

When resistors are connected in parallel, they are linked across the same two points so that each resistor has the same voltage across it. In this arrangement, the total current is divided among the parallel branches, while the overall resistance becomes less than the smallest individual resistor[cite: 2].

The total equivalent resistance, the circuit current and the current through each resistor can be calculated using the following[cite: 2]:

\[ \frac{1}{R_T} = \frac{1}{R_1} + \frac{1}{R_2} + \frac{1}{R_3} \] \[ i_T = i_1 + i_2 + i_3 \] \[ v_T = v_1 = v_2 = v_3 \]

2.3 The Voltage-Divider and Current-Divider Circuits

Voltage Division

A voltage divider is a simple circuit that uses two or more resistors connected in series to produce a fraction of the input voltage. The input voltage is applied across the entire series, and the output voltage is taken across one of the resistors[cite: 2].

\[ v_1 = v_T \frac{R_1}{R_1 + R_2} \] \[ v_2 = v_T \frac{R_2}{R_1 + R_2} \]

Current Division

A current divider is a circuit that distributes an input current into two or more parallel branches. For two parallel resistors, the current through each branch is given by[cite: 2]:

\[ i_1 = i_T \frac{R_2}{R_1 + R_2} \] \[ i_2 = i_T \frac{R_1}{R_1 + R_2} \]

2.4 Star and Delta Connections

Resistor Connection in Star (Y)

In a star (Y) connection, three resistors meet at a single common neutral point[cite: 2]. The transformation from Star to Delta is given by[cite: 2]:

\[ R_{12} = R_1 + R_2 + \frac{R_1 R_2}{R_3} \] \[ R_{13} = R_1 + R_3 + \frac{R_1 R_3}{R_2} \] \[ R_{23} = R_2 + R_3 + \frac{R_2 R_3}{R_1} \]

Resistor Connection in Delta (\(\Delta\))

In a delta connection, three resistors form a closed loop[cite: 2]. The transformation from Delta to Star is given by[cite: 2]:

\[ R_1 = \frac{R_{12} R_{13}}{R_{12} + R_{13} + R_{23}} \] \[ R_2 = \frac{R_{12} R_{23}}{R_{12} + R_{13} + R_{23}} \] \[ R_3 = \frac{R_{13} R_{23}}{R_{12} + R_{13} + R_{23}} \]
